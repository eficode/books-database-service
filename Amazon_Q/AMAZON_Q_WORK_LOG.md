## What Amazon Q Built

### 1. QA Test Runner Agent
**Location**: `.amazonq/agents/qa-runner.py`

**Purpose**: Automated Robot Framework test execution with intelligent reporting

**Features**:
- Poetry dependency management and auto-install
- Test suite selection (sonnet 4.5 / sonnet 4 / both)
- Serial and parallel execution (robot/pabot)
- Auto-rerun failed tests with result merging
- Changed-only mode via git diff
- Tag filtering (smoke, critical, ui, api)
- XML parsing for statistics and failures
- Markdown summary reports with artifacts
- Memory bank integration for test intelligence

**Usage**:
```bash
python3 .amazonq/agents/qa-runner.py all --sonnet-4.5
python3 .amazonq/agents/qa-runner.py all --smoke --rerun
python3 .amazonq/agents/qa-runner.py ui --sonnet-4.5
```

## Key Capabilities Added by QA Test Runner Agent

- **Interactive test suite selection** - Prompts user to choose sonnet 4.5, 4, or both
- **Smart test execution** - Detects Poetry, installs deps, runs tests with appropriate options
- **Intelligent reporting** - Parses XML, generates markdown summaries with stats and failures
- **Rerun automation** - Auto-reruns failed tests and merges results
- **Quick actions** - Provides next-step commands after each run
- **Memory integration** - Reads qa-memory/ for test intelligence (when available)
- **Changed-only mode** - Runs only tests affected by git changes
- **Tag filtering** - Supports smoke, critical, ui, api tags
- **Parallel execution** - Supports pabot for faster test runs
